FR-01 — Ask questions
The user shall be able to submit a natural-language question.

FR-02 — Search approved knowledge
The system shall retrieve information only from documents in the approved knowledge base.

FR-03 — Generate grounded answers
The system shall generate answers using the retrieved document content.

FR-04 — Show citations
The system shall show which document and passage/page support the answer.

FR-05 — Inspect sources
The user shall be able to open or inspect the source used in the answer.

FR-06 — Handle insufficient evidence
If the knowledge base does not contain enough information, the system shall say so rather than fabricate an answer.

FR-07 — Filter by source/domain
The user shall be able to restrict retrieval by source category, such as:
PHMSA
NIST
pipeline regulations
OT cybersecurity

FR-08 — Conversation context
The system shall support follow-up questions within a conversation.

FR-09 — Document ingestion
An administrator or developer shall be able to add documents to the knowledge base.

FR-10 — Retrieval logging
The system shall log which chunks were retrieved for a question.
